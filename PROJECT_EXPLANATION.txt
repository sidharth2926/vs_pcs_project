END-TO-END DIGITAL COMMUNICATION SYSTEM EXPLANATION

This project simulates a complete digital communication chain:

Analog source signal
-> Sampling
-> Quantization
-> PCM bit generation
-> Line coding
-> Pulse shaping
-> AWGN channel
-> Matched filtering
-> Bit detection
-> BER calculation
-> BER vs SNR waterfall curve

The main file to control the project is simulation_template.py. Treat it like
the "test code" file for the assignment. The actual implementation of each
block is inside the comm_system folder.


1. PROJECT STRUCTURE

simulation_template.py
This is the assignment/demo controller. You change variables here to control
the whole system.

main.py
This is a simpler runner. For the assignment, simulation_template.py is more
useful because it has helper functions for every block.

comm_system/config.py
Contains dataclasses that store all simulation parameters.

comm_system/source.py
Generates the analog source signal and samples it.

comm_system/pcm.py
Performs quantization and converts samples into PCM bits.

comm_system/line_coding.py
Converts bits into line-coded signal levels.

comm_system/pulse_shaping.py
Creates NRZ, RZ, raised cosine, sinc, and other pulses, then shapes symbols.

comm_system/channel.py
Adds AWGN noise to the transmitted waveform.

comm_system/receiver.py
Implements the matched filter, bit decision logic, and BER calculation.

comm_system/visualization.py
Creates all plots and eye diagrams.

comm_system/pipeline.py
Connects all blocks together and runs the complete simulation.


2. MAIN SIMULATION FLOW

The full system runs inside run_simulation(config) in comm_system/pipeline.py.

The order is:

1. generate_analog_signal()
2. sample_signal()
3. quantize_samples()
4. build_bitstream()
5. encode_line()
6. build_pulse()
7. shape_symbols()
8. add_awgn()
9. matched_filter_receive()
10. decide_bits()
11. bit_error_rate()
12. render_all_figures()

This is the full transmitter-channel-receiver chain.

4. SOURCE SIGNAL BLOCK

File:
comm_system/source.py

Function:
generate_analog_signal(config.source)

Purpose:
This block generates the analog source signal m(t).

Supported source waveforms:

sine
cosine
square
multi_tone

Important variables:

waveform
Selects the type of analog signal.

amplitude
Controls the height of the main signal.

frequency_hz
Controls the main signal frequency.

phase_rad
Shifts the waveform in phase.

secondary_amplitude
Used for multi_tone signals. Controls the amplitude of the second tone.

secondary_frequency_hz
Used for multi_tone signals. Controls the frequency of the second tone.

secondary_phase_rad
Used for multi_tone signals. Controls the phase of the second tone.

Moves the entire signal up or down.

duration_s
Controls how long the signal exists in seconds.

analog_oversample_factor
Controls how finely the analog signal is represented before sampling.

Important concept:

the analog signal using a dense time array. This is a standard simulation
method.

File:

Purpose:
This block samples the analog signal at regular time intervals.

Important variables:

6. QUANTIZATION AND PCM BLOCK

File:
comm_system/pcm.py

Functions:
quantize_samples()
build_bitstream()
resolve_quantizer_settings()

Purpose:
This block converts sampled analog values into discrete quantized values and
then into binary PCM words.

Important variables:

bits_per_sample
Number of bits used to represent each sampled value.

quantization_levels
Directly sets the number of quantization levels. Use either bits_per_sample
or quantization_levels.

min_value
Minimum input value of the quantizer range.

max_value
Maximum input value of the quantizer range.

How levels are calculated:

If bits_per_sample = 4:
quantization_levels = 2^4 = 16

Quantization step:

step = (max_value - min_value) / (levels - 1)

How it works:

1. The sampled values are clipped between min_value and max_value.
2. Each clipped sample is mapped to the nearest quantization index.
3. Each quantization index is converted to a binary PCM word.
4. All PCM words are flattened into one long bitstream.

Example:

If bits_per_sample = 4 and a sample maps to index 5, then its PCM word is:
0101

Effect of variables:

Increasing bits_per_sample increases accuracy but creates more bits.

Decreasing bits_per_sample creates more quantization error but fewer bits.

Increasing the quantizer range can prevent clipping.

Making the quantizer range too large can waste levels and reduce resolution
near the actual signal values.

Outputs:
quantized_signal
quantizer_indices
pcm_words
bitstream

Saved files/plots:
quantized_samples.csv
quantized_words.txt
bitstream.txt
02_bitstream_preview.png


7. LINE CODING BLOCK

File:
comm_system/line_coding.py

Function:
encode_line(bits, config.line_code)

Purpose:
This block converts binary bits into electrical signal levels.

Supported schemes:

on_off
Bit 1 becomes +A.
Bit 0 becomes 0.

polar
Bit 1 becomes +A.
Bit 0 becomes -A.

bipolar
Bit 1 alternates between +A and -A.
Bit 0 becomes 0.

Important variables:

scheme
Selects on_off, polar, or bipolar.

one_level
The amplitude used for bit 1.

zero_level
The amplitude used for bit 0 in on_off or polar signaling.

bipolar_zero_level
The level used for bit 0 in bipolar signaling. Usually 0.

bipolar_first_mark_positive
Controls whether the first bit 1 in bipolar coding is positive or negative.

Effect of variables:

Increasing one_level increases transmitted signal amplitude.

For polar signaling, changing zero_level changes the level used for bit 0.

For bipolar signaling, changing bipolar_first_mark_positive changes the
starting polarity of the first 1.

Outputs:
line_symbols

Saved files/plots:
line_symbols.txt
03_line_symbols.png


8. PULSE SHAPING BLOCK

File:
comm_system/pulse_shaping.py

Functions:
build_pulse()
shape_symbols()

Purpose:
This block converts line-coded symbols into a waveform by applying a pulse
shape.

Supported pulse shapes:

nrz
Non-return-to-zero rectangular pulse.

rectangular
Same behavior as nrz.

rz
Return-to-zero pulse.

raised_cosine
Raised cosine pulse.

rc
Alias for raised_cosine.

sinc
Sinc pulse.

half_sine
Half-sine pulse.

Important variables:

pulse
Selects the pulse shape.

samples_per_symbol
Controls how many waveform samples represent one bit or symbol.

amplitude
Controls pulse amplitude.

rolloff
Controls the raised cosine rolloff factor.

span_symbols
Controls how many symbol periods the raised cosine or sinc pulse spans.

rz_duty_cycle
Controls how much of one symbol period the RZ pulse remains active.

How shape_symbols() works:

1. It creates an upsampled signal.
2. It places one line-coded symbol every samples_per_symbol samples.
3. It convolves the upsampled symbol stream with the selected pulse.

Mathematically:

waveform = upsampled symbols convolved with pulse

Effect of pulse choice:

NRZ gives a rectangular waveform.

RZ returns to zero during each bit interval.

Raised cosine produces smoother transitions and helps reduce inter-symbol
interference.

Sinc approximates an ideal Nyquist pulse but has ringing due to truncation.

Effect of samples_per_symbol:

Increasing samples_per_symbol gives smoother-looking waveforms and eye
diagrams but increases computation.

Effect of rolloff:

For raised cosine, smaller rolloff gives narrower bandwidth but longer
time-domain ringing. Larger rolloff gives wider bandwidth but better time
localization.

Outputs:
pulse
transmit_waveform

Saved files/plots:
pulse_shape.txt
05_eye_tx.png
08_pulse_time_domain.png
09_pulse_frequency_domain.png


9. AWGN CHANNEL BLOCK

File:
comm_system/channel.py

Function:
add_awgn(signal, config.channel)

Purpose:
This block simulates an additive white Gaussian noise channel.

Important variables:

noise_enabled
Turns noise on or off.

snr_db
Controls signal-to-noise ratio in decibels.

noise_std
Allows manually setting the noise standard deviation. If this is set, snr_db
is not used to calculate noise.

attenuation
Scales the transmitted signal before noise is added.

dc_offset
Adds a constant offset to the channel signal.

random_seed
Controls random noise reproducibility.

Noise calculation:

signal_power = mean(signal^2)
snr_linear = 10^(snr_db / 10)
noise_power = signal_power / snr_linear
noise_std = sqrt(noise_power)

Important note:
The correct relationship is noise_power = signal_power / snr_linear.

Effect of variables:

Increasing snr_db reduces noise and usually reduces BER.

Decreasing snr_db increases noise and usually increases BER.

Setting noise_enabled = False creates a noiseless channel.

Increasing attenuation reduces or increases signal strength depending on its
value.

Changing random_seed changes the exact noise samples.

Outputs:
received_waveform
noise

Saved files/plots:
noise_samples.txt
06_eye_rx.png
04_tx_rx_waveforms.png


10. MATCHED FILTER BLOCK

File:
comm_system/receiver.py

Function:
matched_filter_receive()

Purpose:
This block filters the noisy received waveform using a matched filter.

How it works:

The matched filter is created by reversing the transmit pulse:

matched filter impulse response = pulse[::-1]

Then the received signal is convolved with this reversed pulse:

matched = convolve(received_waveform, pulse[::-1])

Why it is used:

The matched filter maximizes the signal-to-noise ratio at the sampling instant
when the receiver knows the transmitted pulse shape.

Important variables:

sample_offset
Moves the receiver decision sampling point.

samples_per_symbol
Controls spacing between receiver symbol samples.

Effect of variables:

If sample_offset is correct, the receiver samples near the peak of the matched
filter output.

If sample_offset is wrong, the receiver may sample at the wrong time and BER
can increase.

Outputs:
matched_waveform
symbol_samples

Saved files/plots:
07_eye_matched.png
04_tx_rx_waveforms.png


11. BIT DETECTION BLOCK

File:
comm_system/receiver.py

Function:
decide_bits()

Purpose:
This block converts matched-filter symbol samples back into detected bits.

Decision logic:

For on_off:
If sample >= threshold, decide 1.
Otherwise, decide 0.

For polar:
If sample >= threshold, decide 1.
Otherwise, decide 0.
Usually the threshold is 0.

For bipolar:
If abs(sample) >= threshold, decide 1.
Otherwise, decide 0.

Important variables:

decision_threshold
Controls the detection threshold.

normalize_threshold_to_pulse_energy
If True, threshold is multiplied by pulse energy.

bipolar_use_absolute_value
Important for bipolar line coding because both positive and negative pulses
represent bit 1.

Effect of variables:

If threshold is too high, some 1 bits may be detected as 0.

If threshold is too low, noise may cause some 0 bits to be detected as 1.

For bipolar coding, disabling bipolar_use_absolute_value can cause negative
1 pulses to be detected incorrectly.

Outputs:
recovered_bits

Saved files:
recovered_bitstream.txt


12. BER CALCULATION

File:
comm_system/receiver.py

Function:
bit_error_rate(reference_bits, recovered_bits)

Purpose:
This block compares transmitted bits and recovered bits.

Formula:

BER = number of wrong bits / total number of compared bits

Effect:

Low BER means the receiver recovered most bits correctly.

High BER means noise, pulse distortion, threshold error, or timing error is
causing many bit errors.

Saved files:
metrics.json


13. BER VS SNR WATERFALL CURVE

File:
comm_system/pipeline.py

Function:
run_ber_curve()

Purpose:
This block runs the entire transmitter-receiver chain for multiple SNR values
and calculates BER at each SNR.

Important variables:

enabled
Turns BER curve generation on or off.

snr_db_values
The list of SNR values to simulate.

min_bit_count
Number of bits used for each SNR point.

random_seed
Controls the random bit sequence.

bit_source
Can be random or pcm_repeated.

How it works:

1. Generate or repeat a large bitstream.
2. For each SNR value, encode the bits.
3. Pulse shape the encoded symbols.
4. Add AWGN noise for that SNR.
5. Pass through the matched filter.
6. Detect bits.
7. Count bit errors.
8. Save BER for that SNR.
9. Plot BER vs SNR using semilog scale.

Saved files/plots:
ber_vs_snr.csv
ber_vs_snr.json
10_ber_vs_snr_waterfall.png

Expected result:
As SNR increases, BER should decrease. This creates the waterfall curve.

Change line code:

Change pulse:

19. DEMO TALKING POINTS

The analog signal is generated first, then sampled at a chosen sampling rate.

Each sample is quantized into one of a fixed number of levels.

Each quantized level is encoded into a binary PCM word.

The PCM words are flattened into a bitstream.

The bitstream is converted into physical signal levels using a line code.

The line-coded symbols are shaped using a selected pulse.

The shaped waveform is transmitted through an AWGN channel.

The receiver uses a matched filter based on the same pulse shape.

The matched-filter output is sampled at symbol instants.

The sampled values are thresholded to recover bits.

The recovered bits are compared with transmitted bits to calculate BER.

The BER curve is generated by repeating the full chain for multiple SNR
values.


20. IMPORTANT OBSERVATIONS

Higher SNR generally gives lower BER.

More quantization bits reduce quantization error but increase bitstream length.

Pulse shape affects bandwidth, eye opening, ringing, and inter-symbol
interference.

Raised cosine is usually better controlled than raw sinc because rolloff and
span can be adjusted.

The matched filter improves receiver performance by maximizing the sampling
instant response for the known transmitted pulse.

Eye diagrams are useful because they visually show timing margin, noise margin,
and inter-symbol interference.
